# Цифровое портфолио студента (Курсовой проект)

Кроссплатформенное мобильное приложение на **Dart & Flutter** с REST API бэкендом, интеграцией с базой данных **Firebase API** и автоматизированным CI/CD пайплайном сборки под **iPhone (iOS)** и **Android** через **GitHub Actions**.

---

## 📱 Функционал мобильного приложения

1. **Главный экран (Дашборд / Обзор):**
   - Визитная карточка студента (фото, ФИО, направление, кафедра, группа, средний балл GPA).
   - Метрики: общее число проектов, завершенные работы, количество грамот, подтвержденные навыки.
   - Быстрые действия: «Новый проект», «Новая грамота».
   - Секции ключевых проектов и недавних наград.

2. **Модуль «Проекты» (CRUD):**
   - Полнотекстовый поиск по названию, стеку технологий и описанию.
   - Фильтрация по статусу выполнения: «Все», «Завершен», «В разработке».
   - Просмотр подробной карточки проекта (роль, период разработки, теги, кликабельные ссылки на GitHub и Demo).
   - Создание (`POST`), редактирование (`PUT`), удаление (`DELETE`) с подтверждением.

3. **Модуль «Достижения и грамоты» (CRUD):**
   - Фильтрация по категориям: «Хакатон», «Олимпиада», «Наука», «Сертификат», «Конференция».
   - Отображение занятого места (1 место, победитель, финалист), организации, даты выдачи.
   - Добавление, редактирование и удаление наград.

4. **Модуль «Компетенции и навыки» (CRUD):**
   - Группировка: Hard Skills, Soft Skills, Инструменты, Языки.
   - Визуальные индикаторы прогресса (Progress Bar) с градацией: Базовый (30%), Средний (60%), Продвинутый (85%), Эксперт (95%).
   - Интерактивный диалог добавления и настройки навыка со слайдером.

5. **Модуль «Профиль студента» & Настройки:**
   - Редактирование персональной информации, контактов (Email, телефон, Telegram, GitHub) и биографии.
   - **Переключатель источника данных API на лету:**
     - *Node.js Express REST API*
     - *Google Firebase Firestore API*
     - *Автономный оффлайн-кэш* (работает без интернета через локальное хранилище).
   - Смена темы оформления: Светлая / Тёмная (сохраняется между запусками).
   - **Генератор сводки портфолио:** формирование форматированного резюме студента в один клик.

## 🚀 Запуск бэкенда (Node.js + Firebase API)

Сервер находится в директории `backend/` и предоставляет полноценный REST API:

1. Перейдите в папку бэкенда:
   ```bash
   cd backend
   ```
2. Установите зависимости (если еще не установлены):
   ```bash
   npm install
   ```
3. Запустите сервер:
   ```bash
   npm start
   ```
4. Сервер запустится на `http://localhost:3000` (для Android эмулятора доступен по `http://10.0.2.2:3000`).

### Доступные эндпоинты API:
- `GET /health` — проверка работоспособности сервера и БД
- `GET /api/profile` — получение профиля студента
- `PUT /api/profile` — обновление данных профиля
- `GET /api/projects` — список всех проектов
- `POST /api/projects` — добавление нового проекта
- `PUT /api/projects/:id` — редактирование проекта
- `DELETE /api/projects/:id` — удаление проекта
- `GET /api/achievements` — список грамот и дипломов
- `POST /api/achievements` — добавление награды
- `PUT /api/achievements/:id` — редактирование награды
- `DELETE /api/achievements/:id` — удаление награды
- `GET /api/skills` — список навыков
- `POST /api/skills` — добавление навыка
- `PUT /api/skills/:id` — редактирование навыка
- `DELETE /api/skills/:id` — удаление навыка
- `GET /api/stats` — сводная статистика по портфолио

Автотест бэкенда:
```bash
npm test
```

## 📲 Запуск мобильного приложения на Flutter

1. Убедитесь, что установлен Flutter SDK (3.24+):
   ```bash
   flutter doctor
   ```
2. Установите зависимости:
   ```bash
   flutter pub get
   ```
3. Запустите приложение на подключенном смартфоне или эмуляторе:
   ```bash
   flutter run
   ```
4. Для сборки готового установочного файла на Android:
   ```bash
   flutter build apk --release
   ```
   Файл будет создан по пути: `build/app/outputs/flutter-apk/app-release.apk`.

## 🍏 Сборка под iPhone на GitHub Actions

В репозитории настроен автоматический CI/CD воркфлоу `.github/workflows/ios-build.yml`:

1. Опубликуйте проект в ваш GitHub-репозиторий:
   ```bash
   git init
   git add .
   git commit -m "Initial commit: Student Digital Portfolio"
   git branch -M main
   git remote add origin https://github.com/<ваш_аккаунт>/<имя_репозитория>.git
   git push -u origin main
   ```
2. Перейдите во вкладку **Actions** в репозитории на GitHub.
3. Воркфлоу **Build iOS Application** автоматически запустится на виртуальной машине **macOS Latest**.
4. В процессе выполнения:
   - Устанавливается Flutter и CocoaPods.
   - Проверяются тесты (`flutter test`).
   - Собирается iOS-пакет (`flutter build ios --release --no-codesign`).
   - Пакуется артефакт `student-portfolio-ios-release` (`StudentPortfolio_iOS.zip`), который можно скачать прямо со страницы сборки!
